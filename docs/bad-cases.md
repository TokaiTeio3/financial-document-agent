# 真实失败分析

以下样例来自比赛期间的真实运行。预期答案核对了本地 B 榜标注，实际答案核对了 2026-07-26 全量运行输出；证据口径依据提交材料中的复盘。完整题库和 API 日志不公开，仅转述分析所需事实。

每个样例分别记录失败表现、根因与解决方向，并说明实现和验证状态；提出的方案不等于已经完成修复。

| 样例 | 标注答案 | 实际输出 | 主要问题 |
|---|---|---|---|
| fin_b_001 | ACD | CD | 正确页已命中，目标表格行没进入证据窗 |
| fin_b_003 | ABCD | ABD | 独立选项上下文缺少已在同题找到的分母 |
| res_b_005 | 21.74% | 22.27% | 表格精确值与正文近似值的来源选择 |
| fin_b_010 | ABCD | AD | 题面将相对变化率称为百分点 |
| res_b_006 | B | AB | 局部支持无法解释整体选项冲突 |

## fin_b_001：页面命中不代表证据完整

问题要求比较比亚迪两年的分地区收入。2025 年报第 29 页的全口径表格中，2025 年总收入与境外收入分别为 803,964,958、310,740,988 千元；2024 年分别为 777,102,455、221,884,773 千元。境外占比约从 28.55% 上升到 38.65%，差 10.10 个百分点。

检索命中了这一页，但证据窗在分地区目标行之前截断。另一个命中来自第 210 页的部分报告分部，合计和境外收入为 661,094,921、250,151,809 千元，不能直接替代公司全口径收入。A 因缺少操作数被判 unknown，最终漏选。

修复需要区分检索与事实口径：检索层保留表头、目标行、合计行的闭包；事实层记录 `metric_scope`，核对地区收入合计是否对应总营收。只增加 top-k 不足以解决错误口径进入模型的问题。

当前状态：已有表头回溯、部分一致性修复及双向 page overlap 机制；完整表格闭包、口径事实 Schema 及该样例修复后的真实模型验收仍未完成。回归应检查四个操作数和收入范围，不能只断言“命中第 29 页”。

## fin_b_003：同一道题里的事实没共享

问题比较宁德时代与美的的经营现金流率。宁德时代营收和经营现金流分别为 423,701,834、133,219,982 千元；美的分别为 456,451,731、53,345,930 千元。两者比率约为 31.44%、11.69%，相差 19.75 个百分点。

A/B 的模型调用已拿到宁德时代营收。C 的独立上下文却只包含现金流，缺少分母，于是漏选 C。这不是换一个更强模型就一定能解决的问题，已发现的事实没有到达需要它的节点。

解决方向是题级 FactStore 和计算依赖图。先按主体、期间、指标、单位及口径合并带来源的事实，worker 只读取本选项需要的子集；进入 unknown 前，先核对同题存储，再补检索。

当前状态：这是待实现的方案。LangGraph 的追加式 reducer 可以合并结果，但并不等于已经有共享 FactStore。回归应断言计算的四个操作数齐全，并记录重复检索次数。

## res_b_005：计算没错，基准选择有歧义

题目让单车带电量提升到 56kWh 并计算增长。同一研报第 13 页表格给出基准 45.8kWh，第 12 页正文近似写为 46kWh。

系统计算 `(56 / 45.8 - 1) × 100 = 22.27%`，标注按 `(56 / 46 - 1) × 100 = 21.74%`。不能从一次标注匹配就断言表格精确值在业务上错误，真正缺失的是基准来源与题干指代的裁决。

解决方向是保留 `source_type`、精度、是否近似和题干锚点距离；遇到冲突时同时记录候选基准与计算结果，无法判断则明确说明歧义，而非静默选择位数更多的值。

当前状态：精度与来源冲突的专门裁决尚未实现。该样例应该测试“为什么选这个基准”，不只测试四则运算。

## fin_b_010：标注一致与金融语义一致不是一回事

两个选项把倍数从 128.98 降到 33.38、从 15.35 升到 31.95 的变化描述为“约 74.12 / 108.14 个百分点”。这些数值对应的是相对变化率 -74.12%、+108.14%，不是百分点差。

系统按严格术语否定 B/C，标注接受其数值意图，所以出现 ABCD 与 AD 的差异。这里不应简单新增“看到类似数字就选对”的规则，更不能为追求标注一致而在真实金融答案中复述错误术语。

解决方向是同时检查绝对差与相对变化率，输出业务语义结论与题面意图的差异。在竞赛评测中可单独记录意图匹配；面向用户时仍应明确指出术语问题。

当前状态：统一的双语义裁决和专项评测集尚未实现。回归要同时保存公式匹配结果和术语警告。

## res_b_006：逐项成立，合起来冲突

材料描述保险资金减配不动产、增配高股息股票/FVOCI，银行增配政府债。A 把这些动作概括为整体风险偏好下降，B 则强调保险资金是资产间风险置换，风险偏好并未实质下降。

模型分别从局部材料找到 A/B 的支持，输出 AB；标注为 B。它忽略了主体范围、量词和“整体下降”与“未实质下降”的冲突。

解决方向是显式抽取“都、整体、仅、并未”等约束，逐项判断后进行联合一致性检查。综合类问题要能解释题干全部事实，而不只是给某一句话找一个相似片段。

当前状态：统一的选项冲突图尚未实现。不要用多选题最少/最多选几个的先验绕过语义问题。

## 我如何判断改动是否真的有效

先做离线最小测试：目标行是否进入上下文、操作数是否齐全、公式与单位是否正确、冲突是否被显式记录。之后才能用有授权的真实材料做模型回归，比较准确率、调用次数、Token 和延迟。公开 CI 中的合成 fixture 只验证机制与流程，不能宣称这五道真实题已经被修好。
